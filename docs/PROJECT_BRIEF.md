# Project Brief

LeadBridge AI is a verified cross-channel sales-response workflow for small and medium-sized online sellers.

The intended job is to:

- detect buying signals from simulated Facebook, Instagram, TikTok, and email messages
- connect each inquiry to verified product, inventory, delivery, and negotiation information
- draft an appropriate response
- capture qualified leads and provisional orders
- escalate uncertain or consequential actions for human approval

## Competition context

This repository was started after the hackathon began, so the foundation must be explicit about baseline assumptions and evaluation design.

## Phase 1 objective

Build the documentation foundation, evaluation specification, and synthetic evaluation dataset before application implementation begins.

## Non-goals for this phase

- No UI implementation.
- No runtime agent.
- No live integrations.
- No evaluation execution.
- No reported scores.
